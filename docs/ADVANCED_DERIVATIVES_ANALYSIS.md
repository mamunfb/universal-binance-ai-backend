# Advanced Derivatives Trend Analysis

## Endpoints

```http
GET /api/v1/analysis/derivatives/advanced/{symbol}?period=1h&price_interval=1h&limit=48&funding_abs_threshold=0.001&spike_mad_multiplier=3.5
GET /api/v1/history/derivatives-signals/{symbol}?period=1h&limit=100
```

The analysis requires at least six locally stored Open Interest records. It reports sequential OI percentage changes, latest change acceleration, a robust modified-Z candidate using the median absolute deviation (MAD), latest price/OI divergence candidate, latest stored funding event against a caller-supplied absolute threshold, and locally stored force-order events in the selected time window.

## Detection methods and cautions

- OI acceleration is the difference between the latest and previous sequential OI percentage changes, in percentage points.
- OI spike candidate uses the previous OI percentage changes as baseline and the modified Z score `0.6745 * (latest - median) / MAD`. The default multiplier is 3.5 and can be supplied by the caller. A zero MAD or insufficient baseline does not produce a spike classification.
- Positioning context labels price-up/OI-up, price-down/OI-up, and OI-contraction co-movements as candidates only. It does not identify the long or short side.
- Price/OI divergence candidate means the latest observed price return and latest OI percentage change have opposite signs. It is not a confirmed reversal.
- Funding extreme is evaluated against the explicitly supplied absolute rate threshold. The default 0.001 is a configurable starting value, not a market-wide calibrated threshold.
- Liquidation rows are drawn from the latest 1,000 locally stored events for the symbol. SELL and BUY force-order sides are reported separately; no claim is made about complete liquidation volume or trader positioning.

## Signal snapshot storage

Completed analyses are stored in SQLite using `(market, symbol, period, end_time_ms)` as the idempotency key. Re-running analysis for the same end timestamp replaces that snapshot. The database path is configured by:

```env
DERIVATIVES_SIGNAL_DATABASE_PATH=data/derivatives_signals.sqlite3
```

Use persistent disk and a single application process for SQLite. Signal history contains only snapshots generated by this application after this feature is deployed; it does not backfill earlier analyses.

## Research limitations

These metrics describe locally collected public market data. Open Interest does not identify which side initiated positions. Funding is not a standalone directional signal. Liquidation stream data is incomplete. Price and OI observations may be missing or misaligned. No prediction, probability, or trade recommendation is generated.
